Free & open source · runs entirely in your browser

One desk, open at all hours, for every document you write.

Nyxdesk is a lightweight office suite that opens, edits and saves Word, Excel and PowerPoint files — right in the browser, with nothing sent to a server. Fork it, host it on GitHub Pages for free, and make it yours.

Built to be forked, not just used.

01

Nothing leaves your browser

Every file you open is read and written locally with JavaScript. There's no backend, no upload, and no account.

02

Free to host

It's static HTML, CSS and JS — no build step, no server. Push it to a GitHub repository and turn on GitHub Pages.

03

MIT licensed

Use it, rename it, sell services around it, or fold it into a bigger project. Just keep the license notice.

04

Independent project

Nyxdesk is not affiliated with, sponsored by, or endorsed by any office-software vendor. See the README for details.

Nyxdesk reads and writes files compatible with common office document formats for interoperability only. Format names mentioned in the README refer to open file-format standards, not to any vendor's trademarks, and no vendor names, logos, or branding are used anywhere in this project.
